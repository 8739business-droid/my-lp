## 執筆ルール

1. **学習者像**：飲食店運営10年以上、広告運用でROAS 300〜800%の実績、月30〜100万円の予算運用経験。北海道ニセコ・倶知安の宿泊施設と飲食店が初期顧客。マーケ初歩の説明は不要、映像制作は基礎から。
2. **禁止**：「〜しましょう」の連呼、中身のない励まし、マーケ用語の辞書的説明、AIが生成したような無個性な一般論。
3. **必須**：数値・判断基準・失敗の因果・実務の段取り。「どう判断するか」を必ず書く。
4. **断定禁止**：動画制作で予約や売上が必ず増えるとは書かない。要因が複数あることを前提に、検証の仕方を書く。
5. **UI名称**：Higgsfield のUIは変更されうる。断定的な画面名の多用を避け、「〜に相当する機能」という書き方を併用する。モデル名を挙げる場合は「執筆時点」と明示。
6. **プロンプト**：英語で書く。被写体 / 動作 / 環境 / カメラ / 光 / 質感 / スタイル の要素が識別できる構造にする。status は必ず "未検証"。
7. **所要時間**：合計が duration と一致すること。60〜90分。
